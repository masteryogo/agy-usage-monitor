# Antigravity Dashboard Control

Run the bundled control script with `on`, `off`, `toggle`, or `status`:

```bash
python ~/.gemini/config/skills/agy-dashboard/scripts/dashboard_control.py status
```

On Windows PowerShell:

```powershell
python "$env:USERPROFILE\.gemini\config\skills\agy-dashboard\scripts\dashboard_control.py" toggle
```
